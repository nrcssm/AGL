# AGL
Smart cataloger for your free (and not-so-free) games

Each of us has faced a situation where the library of games grows to dozens of labels on the desktop. This is especially true for indie projects, free novelties and old classic games that we download from the web. Launching games that you didn’t buy on Steam is not very convenient due to the overloaded interface and in principle too big for this program, and some other third-party launchers may also be too busy for a simple task - to find and launch the game, as well as their interface is far from ideal. Everyone has their reasons.

I developed my launcher - a lightweight program that solves this problem. This is not just the "Start" menu for games, but a smart tool that automatically collects information about your game.

How does it work?
Everything is as simple as possible. You run the program and click on the "Add game" button. All you need to do is select an EXE file for the game or a shortcut on your desktop. Then the magic begins:

Autodetermination: The program analyzes the file and is 99% likely to recognize the name of the game and its genre (if there may be similar matches, the program suggests selecting the correct option).
Cover search: Using a recognized title, the launcher automatically goes to databases online and downloads the official cover for your game.
Manual mode: If the automation has failed (for example, a game with a complex title or a self-written project), you simply enter the ID of the game in Steam manually and the program pulls the necessary data. You can find the ID on steamdb.info/. There, for each game, is an App ID. For example, for Cyberpunk 2077 it’s 1091500.
After that, the game appears in your personal library inside the launcher, from where you can launch and finish the game in one click.

🛠 Features
Auto-define metadata (Name, Genre, Cover).
Convenient library network.
Quick start and finish without unnecessary windows.
Time-in meter
The most recent games section to access the games you’re playing now.
Grid settings, sorting, changing cover sizes
Choose a light and dark theme
Name search, genre
Change the background from semi-transparent to colored (color is selected in settings) or choose a background image.
Automatic start-up on Windows login
Import and export a game library for backup

Installation instructions

Download the archive with the program by link above.
Unzip the archive to any folder (no installation required).
Run the AGL.exe executable file
Click the add button and select any game ( .exe file).
